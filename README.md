# 🎓 Ghorpade Classes – Coaching Institute Website

A modern, responsive website built for **Ghorpade Classes** to showcase coaching programs, build trust with students and parents, and make it easy to contact the institute.

The website is built using **Next.js and Tailwind CSS**, focusing on **fast performance, clean UI, and mobile responsiveness**.

---

# 🚀 Live Demo

[👉 Demo LInk](https://ghorpade-classes-landing-page.vercel.app/)

This project is deployed on **Vercel** and automatically updates whenever new changes are pushed to GitHub.

---

# ✨ Overview

The **Ghorpade Classes Website** is designed for coaching institutes that want a **professional online presence**.

The website supports **both Marathi and English languages**, making it accessible for students and parents in the local region.

The layout focuses on:

📚 Presenting coaching programs
🎓 Highlighting teaching quality
⭐ Showing student testimonials
📸 Displaying class/gallery images
📱 Providing a smooth mobile experience
📞 Making it easy for students to contact the institute

---

# 🚀 Features

✔️ **Marathi + English language support**
✔️ Modern responsive UI

# 🧩 Landing Page Sections

The homepage is built using modular React components.

## 🏠 Hero Section

Introduces the coaching institute with a strong headline and call-to-action.

## ⭐ Trust Strip

Highlights the credibility and strengths of the coaching institute.

## 📚 Boards Section

Displays supported boards such as:

* SSC
* HSC
* CBSE
* ICSE

## ⚠️ Problem Section

Shows common academic problems faced by students.

## ✅ Solution Section

Explains how **Ghorpade Classes helps students improve their performance**.

## 📸 Gallery Section

Displays classroom photos and coaching activities.

## ⭐ Testimonials

Student feedback and success stories that build trust.

## 📞 Final Call To Action

Encourages students and parents to contact the institute.

# ⚙️ Installation

Clone the repository

```
git clone https://github.com/MohseenAH/Ghorpade-classes-landing-page.git
```

Navigate into the project folder

```
cd ghorpade-classes
```

Install dependencies

```
npm install
```

Run the development server

```
npm run dev
```

Open in your browser

```
http://localhost:3000
```
